# 🚀 Abdelrhman's Builder Page

Hello! I'm **Abdelrhman Ali**, a 17-year-old STEM student and maker from Egypt (STEM October 11th District). I love building hardware prototypes, working on renewable energy systems, and training AI models for real-world problems.

This repository contains the source code for my personal portfolio website, built from scratch using pure HTML and CSS as part of the **Hack Club Pixl** initiative.

## 🌐 Live Demo
[View my live portfolio here](https://abdelrman32-dot.github.io/Personal-builder-page/)

## 🛠️ Projects Featured
* **AquaAI - Smart Irrigations:** A system predicting water resource needs for farms to irrigate by actual need instead of a fixed schedule.
* **Hybrid Savonius Wind Turbines:** A 0.25 m³ vertical-axis wind and hydro energy generator designed for my STEM capstone project.
* **Sign Language Reader:** A computer vision model trained using PictoBlox to recognize hand signs in real-time and convert them into speech.
* **Medical Nanoparticle Research:** Targeted core-shell nanoparticles for drug delivery, presented at UGRF and ISEF.
